## What is This?

P4wnP1_aloa is a Raspberry Pi Zero W firmware that conceals itself and emulates various USB devices such as mouse, keyboard, or even a Hard Drive. While giving malicious actors the ability to perform attacks such as keyboard injection, credential harvesting, and other hardware based attacks.

**This repo documents:**
- Deployment on a £20 Raspberry Pi Zero W
- Configuration for common attack scenarios
- Payload examples (educational). 
- Defensive countermeasures
- Lessons learned in a lab environment.
